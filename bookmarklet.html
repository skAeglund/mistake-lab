Drag this button to your bookmarks bar:

♟ Grab Position

How to use

  1. Drag the "♟ Grab Position" button above to your bookmarks bar
  2. Go to Chessable (or any chess site) and navigate to a position you got wrong
  3. Click the bookmarklet in your bookmarks bar
  4. The FEN is copied to your clipboard
  5. Go to MistakeLab → Repertoire → Add position and paste the FEN
  6. If the position exists in your repertoire, the correct move is auto-filled!

How it works

The bookmarklet tries several strategies to extract the board position:

  1. React fiber on #board — walks the React component tree looking for a fen prop (works on Chessable)
  2. data-fen attributes in the DOM
  3. Global JavaScript chess objects (window.chess, window.game)
  4. React fiber on chessground elements (cg-board)
  5. React fiber on any element with "board" in its id or class
  6. If all else fails, prompts you to paste the FEN manually
Tip: If the position exists in your MistakeLab repertoire, the correct move is auto-filled when you paste the FEN. No need to remember it!

Compatibility

Confirmed working on: Chessable (React fiber extraction). Also supports Lichess, Chess.com analysis board, and any site using chessground, chessboard.js, or React-based chess boards with a fen prop.
